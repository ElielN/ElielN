### `01 / About me`

I'm a **software engineer with 5+ years of experience** building web applications, APIs, and user interfaces, including experience leading frontend development.

These days, a big part of my work is in **AI training and evaluation for software engineering**. I review AI-generated code and technical answers, compare model responses, check instruction following, and assess quality using evaluation rubrics. My development background helps me catch subtle bugs, question assumptions, and give feedback grounded in how software actually works.

I'm also expanding my Python skills as I move further into AI engineering.

**🧠 AI training & evaluation**
- Reviewing AI-generated code for correctness, edge cases, and practical quality.
- Evaluating technical answers for accuracy, clarity, and instruction following.

- Working with structured annotation tasks where consistency and attention to detail matter.

**💻 Software engineering**
